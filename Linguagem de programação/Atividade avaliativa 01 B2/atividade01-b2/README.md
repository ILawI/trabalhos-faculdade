# Atividade Avaliativa 01 - B2

Cinco classes em Java, cada uma com seus atributos, métodos e regras de negócio, e um programa principal (`Main.java`) que testa todas.

| Arquivo | Atividade |
|---|---|
| `Estacionamento.java` | 1 - Cobrança de estacionamento por tempo |
| `MaquinaRefrigerante.java` | 2 - Máquina de refrigerantes com estoque e troco |
| `Time.java` | 3 - Pontuação de times em um campeonato |
| `Cofrinho.java` | 4 - Cofrinho com depósitos, retiradas e meta |
| `Pedido.java` | 5 - Pedido de restaurante com desconto e taxa de entrega |
| `Main.java` | Programa principal que executa as 5 atividades |

## Como executar

```bash
javac *.java
java Main
```
