# Sistema de Biblioteca

Atividade avaliativa 02 B2 - Parte 1 - sistema de biblioteca feito com base no projeto da locadora.

## O que o sistema faz

- Listar, buscar, cadastrar e excluir livros
- Cadastrar e listar usuários
- Emprestar e devolver livros
- Ver o histórico de empréstimos

## Regras

- Cada usuário pode ficar com no máximo 2 livros ao mesmo tempo
- Um livro emprestado não pode ser emprestado de novo nem excluído
- O sistema já começa com alguns livros e usuários cadastrados

## Classes

- `Main`: menu e leitura dos dados
- `Biblioteca`: guarda as listas e faz as operações
- `Livro`, `Usuario` e `Emprestimo`: dados de cada objeto

Pra rodar é só abrir no Eclipse e executar a classe `Main`.
