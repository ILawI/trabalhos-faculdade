# Cadastro de Jogos

Atividade avaliativa 02 B2 - Parte 2 - CRUD em Java com POO, usando menu no console.

## O que o sistema faz

- Cadastrar jogo (o ID é gerado sozinho e não se repete)
- Listar todos os jogos
- Buscar jogo pelo ID
- Atualizar os dados de um jogo
- Excluir um jogo

O sistema já começa com 3 jogos cadastrados (GTA V, ARK: Survival Ascended e Valorant).

## Classes

- `Jogo`: atributos privados (id, nome, gênero e plataforma), construtor, getters e setters
- `Main`: menu, `ArrayList` com os jogos e os métodos de cada opção

Pra rodar é só abrir no Eclipse e executar a classe `Main`.
